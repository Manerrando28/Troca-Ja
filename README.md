# TrocaJá 📱

Aplicativo de marketplace de trocas, desenvolvido em **React Native com Expo Router**.  
O objetivo é criar uma plataforma simples e moderna para troca de produtos entre usuários.

---

## ✅ O que já foi feito
- Tela de **Login** com fundo azul moderno e ícone central 🔑
- Tela de **Início** com ícone central 🏠 e botões arredondados coloridos
- Tela de **Feed** com lista de produtos e espaço reservado para imagens
- Tela de **Explore** com categorias horizontais (Eletrônicos, Roupas, Livros)
- Tela de **Profile** com avatar, dados do usuário e lista de produtos
- Navegação entre telas com **expo-router**
- Layout moderno: cores consistentes, botões arredondados e ícones
